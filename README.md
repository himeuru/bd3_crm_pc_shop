# CRM PC Shop

Десктопное CRM-приложение для сети магазинов компьютерных комплектующих. Написано на **C++ / Qt 6**, база данных — **PostgreSQL 16**.

---

## Стек технологий

| Компонент | Технология |
|---|---|
| Язык | C++17 |
| UI фреймворк | Qt 6 (Widgets, SQL) |
| База данных | PostgreSQL 16 |
| Хеширование паролей | bcrypt (pgcrypto) |
| Поиск | Полнотекстовый (tsvector) + нечёткий (pg_trgm) |
| Сборка | qmake |

---

## Функциональность

Система реализует три роли с независимыми интерфейсами.

### Директор

- Управление магазинами (открыть / закрыть — блокирует продажи триггером)
- Найм и увольнение продавцов, изменение окладов с автоматическим журналом
- Просмотр заказов, отмена заказов с возвратом товара на склад
- Управление складом: пополнение микросклада из центрального склада
- Шесть типов отчётов: продажи по месяцам, зарплатная ведомость, топ товаров, топ категорий, история зарплат, журнал переводов склада

### Продавец

- Оформление заказов: поиск и фильтрация товаров по 11 категориям, корзина, подтверждение с детальным составом
- Автоматический учёт персональной скидки клиента в ценах
- Регистрация новых клиентов, изменение скидки
- Просмотр остатков на микроскладе
- Зарплатная ведомость: оклад + комиссия с продаж по месяцам

### Клиент

- Каталог товаров с фильтром категорий и поиском, цены с учётом скидки
- Список желаний: добавление товаров, копирование в буфер обмена
- История заказов с детальным составом
- Смена пароля

## Архитектура

```
crm_pc_shop/
├── core/               # DatabaseManager, Session, AppConfig
├── models/             # Структуры данных (Shop, Product, Employee, …)
├── repositories/       # SQL-запросы по сущностям
├── controllers/        # Бизнес-логика
└── ui/
    ├── widgets/        # SqlTableWidget — переиспользуемая таблица
    ├── director/       # Окно и 5 вкладок директора
    ├── seller/         # Окно и 4 вкладки продавца
    └── client/         # Окно и 4 вкладки клиента
```

**Ключевые архитектурные решения:**

- Вся критическая бизнес-логика реализована в **хранимых функциях PostgreSQL** (`create_order`, `cancel_order`, `replenish_micro_warehouse`, `hire_employee` и др.) — это гарантирует атомарность и целостность данных независимо от клиента
- Пароли хранятся в виде **bcrypt-хешей** через `crypt(password, gen_salt('bf', 12))`
- SQL-запросы используют прямой `exec()` вместо `prepare()/bindValue()` из-за особенности Qt QPSQL-драйвера (конфликт безымянных prepared statements)
- Автообновление данных в интерфейсе директора каждые 15 секунд через `QTimer`

## База данных

10 таблиц, 9 функций, 2 триггера, 3 представления.

```
shops               — магазины
warehouses          — склады (main / micro)
products            — товары с полнотекстовым поиском
warehouse_stock     — остатки (warehouse_id, product_id) → quantity
employees           — сотрудники (director / seller)
clients             — клиенты с персональной скидкой
orders              — заказы
order_items         — позиции заказа (денормализованы для быстрых отчётов)
salary_log          — журнал изменений окладов
stock_transfer_log  — журнал переводов между складами
```

**Ключевые ограничения БД:**
- Один активный директор на магазин (частичный уникальный индекс)
- Триггер блокирует продажи в закрытом магазине
- `quantity >= 0` — отрицательный остаток невозможен
- Составные FK гарантируют принадлежность продавца тому же магазину что и заказ

## Установка и запуск

### Требования

- Qt 6.2+ с модулями `widgets` и `sql` (QPSQL driver)
- PostgreSQL 16+
- Windows: дополнительно `libpq.dll` в папке с exe

### Настройка базы данных

1. Создайте базу данных `crm_pc_shop` в pgAdmin
2. Подключитесь к ней и выполните скрипт:

```sql
-- В pgAdmin Query Tool (F5):
-- Вставьте содержимое setup_clean.sql (без комментариев)
-- или setup_commented.sql (с пояснениями)
```

3. Пользователь приложения создаётся автоматически:
   - Логин: `crm_app`
   - Пароль: `crm_secure_2025`

### Сборка

```bash
git clone <repo>
cd crm_pc_shop
qmake crm_pc_shop.pro
make          # Linux/macOS
# или: mingw32-make  (Windows с MinGW)
```

В `.pro` файле укажите путь к PostgreSQL если он отличается от стандартного:

```qmake
POSTGRESQL_PATH = "C:/Program Files/PostgreSQL/16"
```

### Первый запуск

1. Запустите `crm_pc_shop.exe`
2. В диалоге подключения: `127.0.0.1:5432`, база `crm_pc_shop`, пользователь `crm_app`
3. При первом запуске с пустой БД откроется мастер создания первого магазина и директора
