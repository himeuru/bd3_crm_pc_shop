# Руководство пользователя — CRM PC Shop

Система управления магазином компьютерных комплектующих. Три роли: **директор**, **продавец**, **клиент**.

---

## 1. Первый запуск

### 1.1 Настройка базы данных

1. Создайте базу данных `crm_pc_shop` в pgAdmin
2. Откройте Query Tool (`Ctrl+Shift+Q`), вставьте содержимое `setup_clean.sql` и выполните (`F5`)
3. Дождитесь завершения — в Messages должно быть `Query returned successfully`

Если база уже существует и нужно начать заново:
```sql
DROP SCHEMA public CASCADE;
CREATE SCHEMA public;
GRANT ALL ON SCHEMA public TO postgres;
GRANT USAGE ON SCHEMA public TO crm_app;
```
Затем снова выполните `setup_clean.sql`.

### 1.2 Подключение приложения

1. Запустите `crm_pc_shop.exe`
2. В диалоге подключения введите:
   - Хост: `127.0.0.1` / Порт: `5432`
   - База: `crm_pc_shop`
   - Пользователь: `crm_app` / Пароль: `crm_secure_2025`
3. Нажмите **«Проверить»** → **«Подключиться»**

### 1.3 Тестовые логины

| Роль | Логин | Пароль | Магазин |
|---|---|---|---|
| Директор | `director_msk` | `Dir2025!` | Москва |

## 2. Интерфейс директора

### Вкладка «Магазины»

Таблица всех магазинов сети: название, адрес, статус, маржа директора, директор, количество продавцов.

**Открыть / Закрыть магазин** — выберите строку, нажмите соответствующую кнопку. Закрытый магазин блокирует все продажи (продавцы получат ошибку при попытке создать заказ).

### Вкладка «Сотрудники»

Список сотрудников текущего магазина директора.

**Нанять продавца:** нажмите «+ Нанять», заполните форму (ФИО, логин, пароль, оклад). Нельзя нанять второго директора — система вернёт ошибку.

**Изменить зарплату:** выберите сотрудника → «Изменить зарплату» → введите новую сумму. Каждое изменение автоматически записывается в журнал (виден в Отчётах).

**Уволить:** выберите сотрудника → «Уволить» → подтвердить. Данные сохраняются, история заказов не теряется.

### Вкладка «Заказы»

Список заказов своего магазина с фильтрами по дате и статусу.

**Просмотр состава:** кликните на строку заказа — внизу появятся позиции с ценами и прибылью.

**Отменить заказ:** выберите заказ со статусом «Выполнен» → «Отменить заказ» → подтвердить. Товары автоматически возвращаются на микросклад.

### Вкладка «Склад»

Слева — главный склад (общий для всей сети). Справа — микросклад вашего магазина.

**Пополнить микросклад:** установите целевое количество в спиннере → «Пополнить». Система покажет сколько позиций и единиц будет перенесено. Каждый перевод записывается в журнал.

### Вкладка «Отчёты»

Шесть типов отчётов, все с фильтром по диапазону дат:

| Отчёт | Содержимое |
|---|---|
| Продажи по месяцам | Заказов, выручка, валовая прибыль |
| Зарплатная ведомость | Оклад + комиссия = итого по каждому продавцу |
| Топ товаров | Рейтинг по количеству продаж и выручке |
| Топ категорий | Выручка и прибыль по категориям (CPU, GPU и т.д.) |
| История зарплат | Все изменения окладов с датами |
| История пополнений склада | Журнал переводов товаров |

## 3. Интерфейс продавца

### Вкладка «Новый заказ»

**Пошаговый порядок оформления:**

**Шаг 1 — Найти клиента.** В строке «Клиент» введите логин (`client_001`) или телефон (`+79001234567`), нажмите «Найти» или Enter. При успехе имя клиента окрасится зелёным, рядом появится его скидка. Цены в таблице товаров пересчитаются с учётом скидки.

**Шаг 2 — Выбрать товары.** Таблица загружается автоматически. Используйте фильтр категорий (CPU / GPU / RAM / SSD / PSU / MB / COOL / HDD / CASE / PERIPH / MONITOR) или строку поиска. При выборе строки внизу отображается «На складе: X шт.», счётчик количества ограничивается этим значением.

**Шаг 3 — Добавить в корзину.** Установите количество в спиннере и нажмите «+ В корзину». Либо дважды кликните по строке товара (добавляет 1 шт.). Если товар уже в корзине — количество суммируется.

**Шаг 4 — Оформить заказ.** Нажмите «Оформить заказ» — откроется диалог с составом и итоговой суммой. После подтверждения заказ создаётся, остатки на складе уменьшаются.

Кнопка «Сбросить» рядом с именем клиента — снять выбор и очистить скидку.

**Возможные ошибки:**
- `Нет товара на складе` — попросите директора пополнить микросклад
- `Магазин закрыт` — директор должен открыть магазин в своём интерфейсе

### Вкладка «Клиенты»

**Зарегистрировать клиента:** «+ Зарегистрировать клиента» → ФИО, телефон, логин, пароль, скидка (0–50%). После регистрации клиент может войти в личный кабинет.

**Изменить скидку:** выберите клиента → «% Изменить скидку» → введите новый процент.

### Вкладка «Склад»

Остатки на микроскладе магазина, отсортированные по возрастанию — товары с наименьшим запасом сверху.

### Вкладка «Зарплата»

Верхняя таблица — заработок по месяцам (оклад + комиссия = итого). Если заказов нет — отображается текущий месяц с нулевой комиссией. Нижняя — список всех заказов с размером комиссии по каждому.

## 4. Интерфейс клиента

### Вкладка «Каталог»

Все активные товары с ценами с учётом персональной скидки. Зелёный баннер вверху сообщает что скидка уже учтена. Фильтр по категории + поиск по названию и описанию.

### Вкладка «Список желаний»

Составьте список нужных товаров и покажите его продавцу — он оформит заказ с вашей скидкой.

Добавление: кликните по строке товара → «+ В список» или двойной клик. Кнопка «Скопировать список» копирует список в буфер обмена в текстовом формате.

### Вкладка «Мои заказы»

История всех заказов. Кликните на заказ — внизу появится детальный состав с ценами.

### Вкладка «Профиль» — смена пароля

Введите текущий пароль, новый пароль (минимум 6 символов) и подтверждение, нажмите «Сменить пароль».

## 5. Типичные проблемы

| Проблема | Решение |
|---|---|
| Микросклад пустой | Директор → Склад → установить количество → «Пополнить» |
| Ошибка «Нет товара на складе» | То же что выше |
| Ошибка «Магазин закрыт» | Директор → Магазины → выбрать → «Открыть магазин» |
| Таблицы пустые после запуска | Выполнить `setup_clean.sql` в pgAdmin |
| Не подключается к БД | Проверить что PostgreSQL запущен, crm_app создан |
| Нельзя нанять второго директора | Нормальное поведение — один директор на магазин |

### Полный сброс данных

```sql
TRUNCATE TABLE stock_transfer_log RESTART IDENTITY CASCADE;
TRUNCATE TABLE salary_log         RESTART IDENTITY CASCADE;
TRUNCATE TABLE order_items        RESTART IDENTITY CASCADE;
TRUNCATE TABLE orders             RESTART IDENTITY CASCADE;
TRUNCATE TABLE warehouse_stock    RESTART IDENTITY CASCADE;
TRUNCATE TABLE employees          RESTART IDENTITY CASCADE;
TRUNCATE TABLE clients            RESTART IDENTITY CASCADE;
TRUNCATE TABLE warehouses         RESTART IDENTITY CASCADE;
TRUNCATE TABLE products           RESTART IDENTITY CASCADE;
TRUNCATE TABLE shops              RESTART IDENTITY CASCADE;
```

Затем снова выполните `setup_clean.sql`.

## 6. Про скидки

Скидка применяется на уровне базы данных в функции `create_order`:
1. При поиске клиента приложение загружает `discount_pct` из таблицы `clients`
2. Цены в таблице товаров пересчитываются функцией `calc_sale_price(cost, seller_pct, director_margin, discount_pct)`
3. При оформлении заказа функция `create_order` читает `discount_pct` напрямую из БД по `client_id` — независимо от UI
4. В таблице `orders` сохраняется снимок `discount_pct` на момент заказа
5. В `order_items` сохраняются финальные цены `sale_price` уже с учётом скидки

Это означает что скидка применяется гарантированно на уровне транзакции в PostgreSQL.
